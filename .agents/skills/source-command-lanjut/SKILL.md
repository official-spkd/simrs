# source-command-lanjut

Use this skill when the user asks to run the migrated source command `lanjut`.

## Command Template

Baca `AGENTS.md` dan `docs/PROGRESS.md`. Tentukan langkah berikutnya yang belum selesai (fase berjalan, potongan berikutnya).
Jelaskan dalam 3–5 baris apa yang akan dikerjakan dan kenapa, lalu tampilkan rencana singkat dan tunggu persetujuan.
Setelah disetujui, kerjakan dengan siklus: implementasi → tes hijau → commit → perbarui PROGRESS.md.
