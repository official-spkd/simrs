# source-command-cek-mrmik

Use this skill when the user asks to run the migrated source command `cek-mrmik`.

## Command Template

Gunakan `docs/03-regulasi-mrmik.md` sebagai daftar elemen. Untuk setiap EP yang relevan dengan fase yang sudah dikerjakan:
- tentukan status: terpenuhi / sebagian / belum / bukan ranah sistem (prosedur RS);
- sebutkan bukti konkret: file + fungsi, migrasi, tes, atau layar;
- untuk yang sebagian/belum, usulkan tindakan minimal dan fase penanganannya.
Tulis/perbarui hasilnya di `docs/MRMIK-MATRIX.md` (tabel: EP · status · bukti · tindakan). Jangan mengubah kode pada perintah ini.
